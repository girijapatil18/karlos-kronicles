## Project Overview

CampusEscape is an Android pixel-art adventure game following Karlos through a strange campus nightmare. The game combines story dialogue sequences with multiple mini-games, including a haunted cafe maze, a Wordle-style puzzle, and a final campus race where the player avoids monsters, manages health, and progresses through the narrative.
